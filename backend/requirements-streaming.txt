# WHY THIS IS SEPARATE
#   The application ships and runs in DIRECT mode. In direct mode the Pathway
#   code path is never reached: engine.rag_state() and engine.scan_policy_files()
#   both return early with "Policy RAG requires the Pathway runtime", listing the
#   policy files present on disk without embedding them. The imports below are
#   consequently never executed by the deployed system.
#
#   Folding them into runtime cost several GB of OCR and embedding machinery, a
#   torch install in the Dockerfile, and a Linux-only constraint (Pathway ships
#   no Windows wheels) — all to support a path that does not execute.
#
# THE PATHWAY DECISION IS STILL OPEN
#   Pathway is NOT being deleted. Whether the streaming engine is revived,
#   replaced or retired is a separate decision. This file's job is only to stop
#   an undecided dependency from being mandatory in the meantime.
#
# Install with:
#   pip install -r backend/requirements.txt -r backend/requirements-streaming.txt
# Expect resolution work: these pins have not been tested together.
